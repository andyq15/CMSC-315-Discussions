# Unit 8 Discussion: Breadth-First Search (BFS)

## Overview

This assignment explores graph traversal using Breadth-First Search (BFS).

## Learning Objectives

- Represent graphs using adjacency lists
- Implement BFS
- Use queues in graph traversal
- Analyze graph traversal behavior

## Requirements

1. Create a graph.
2. Perform BFS traversal.
3. Add nodes or edges.
4. Demonstrate edge cases.
5. Analyze BFS behavior.
6. Create a real-world graph example.

While completing this assignment, I learned more about how Breadth-First Search (BFS) is used to traverse graphs and how a queue controls the order in which nodes are visited. I also learned how an adjacency list can be used to represent connections between nodes and why a visited set is important for preventing nodes from being processed more than once. One challenge I encountered was understanding how BFS keeps track of which nodes should be visited next. I overcame this by working through the graph step by step and seeing how nodes are added to and removed from the queue. I also tested my program with different starting nodes and edge cases to make sure it worked correctly. BFS and Depth-First Search (DFS) both traverse graphs, but they use different approaches. BFS explores nodes level by level using a queue, while DFS explores as far as possible along one path before backtracking, usually using recursion or a stack. BFS can be useful for finding the shortest path in an unweighted network, such as finding connections between people or routes between locations. DFS can be useful for tasks such as exploring file systems, solving mazes, and analyzing connected components.
