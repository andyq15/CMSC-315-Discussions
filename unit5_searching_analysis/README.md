# Unit 5 Discussion: Search Algorithms

## Overview

This assignment compares linear search and binary search.

## Learning Objectives

- Implement linear search
- Implement binary search
- Compare performance
- Analyze algorithm efficiency

## Requirements

1. Test both algorithms on a small dataset.
2. Test both algorithms on a large dataset.
3. Demonstrate edge cases.
4. Analyze performance.
5. Create a real-world search scenario.

While working on this assignment, I learned more about how linear and binary searches actually work instead of just knowing their names. I learned that linear search goes through the list one item at a time, while binary search checks the middle and cuts the search area in half each time. This helped me understand why linear search is O(n) and binary search is O(log n).

One challenge I had was getting the binary search to work correctly. I had to understand how the beginning, middle, and ending positions change after each search. Testing it with a small list made it easier to see what was happening and helped me fix any mistakes.

I think linear search is better when you have a small or unsorted list because it is simple and does not require the data to be organized. Binary search is better for larger datasets when the information is already sorted. The biggest tradeoff is that binary search is much faster, but keeping the data sorted can take extra work.
